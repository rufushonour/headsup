First stable release. Heads Up puts a full-screen alert on every display right before your meetings start, so you actually see it — pulls from your calendars, finds the Zoom/Meet/Teams link automatically, and lets you snooze or join straight from the alert.

What's new since 0.5.3:
- Launch at login, offered on first run and adjustable anytime in Settings
- Update notifications now show real release notes instead of a bare changelog link

Recent fixes:
- Snoozing an alert no longer reopens it within seconds — it now actually waits out the snooze duration you picked
- Join links wrapped by Microsoft Defender Safe Links (common on Microsoft 365) now resolve to the real Zoom/Meet/Teams URL instead of falling back to the wrong link
- Fixed Calendar access never prompting on notarized builds
- Real copyright notice in the About panel
